# Dash Miner Lite (Beta)

Gestiona tu granja de mineros ASIC desde tu LAN: escaner de red con bridge
integrado (Bitmain, MicroBT, Canaan, Goldshell, IceRiver, Jasminer, Bitdeer,
Nerdminer/Nerdaxe), gestion de equipos, rentabilidad y pools — sin nube.

**BETA (0.1.0-beta.1)** — primera version publica, en pruebas.
Imagen: `ghcr.io/refugioos/dash-miner-lite:0.1.0-beta.1` (amd64 + arm64).
Requiere red host para que el bridge descubra la LAN real.
